# プライバシーポリシー

最終更新: 2026-08-02

本ページは「株式レポートサービス」（以下「本サービス」）における個人情報の取り扱いを
定めるものです。本サービスは日本国内および米国在住の方を主な対象として提供しており、
**欧州経済領域(EEA)・英国・スイス在住の方は対象としていません**（詳細は末尾「対象地域」参照）。

## 1. 収集する情報

本サービスが収集する情報は、以下の3種類のみです。

| 情報 | 用途 | 収集タイミング |
|---|---|---|
| メールアドレス | レポート配信、登録確認、サービスからのお知らせ | お申込みフォーム入力時 |
| 登録した銘柄（ティッカーシンボル） | 監視レポートの生成 | 銘柄登録操作時 |
| 判定期間モードの選択（短期/中期/長期） | レポート内容のカスタマイズ | モード変更操作時 |

**上記以外の情報は収集していません。** 具体的には、以下を一切行っていません。

- クレジットカード番号・決済情報の収集（本サービスは無料で提供しており、決済機能自体を持ちません）
- 氏名・住所・電話番号などの追加個人情報の収集
- IPアドレスのログ記録・保存
- Cookieやトラッキングピクセルによる行動追跡
- 第三者への個人情報の提供・販売

## 2. 情報の保存方法

メールアドレス・登録銘柄・期間モードは、Amazon Web Services (AWS) の
DynamoDB（東京/米国リージョンのデータベースサービス）に保存します。
アクセスには招待トークン（お申込み時に発行される固有の文字列）が必要で、
このトークンを知らない第三者は登録内容の閲覧・変更ができません。

## 3. 情報の利用目的

- 選定レポート・監視レポートのメール配信
- 登録内容（監視銘柄・期間モード）の反映
- サービスの不具合発生時のエラー通知（開発者宛、利用者の個人情報は含みません）

上記以外の目的（マーケティング分析、第三者への提供等）には利用しません。

## 4. 広告・アフィリエイトについて

本サービスは将来的に、Webページ上に**非パーソナライズ広告**（利用者個人を特定・追跡しない
広告）または**アフィリエイトリンク**（証券会社等の紹介リンク）を掲載する可能性があります。
掲載する場合は、以下を遵守します。

- 個人を特定する形での広告配信（パーソナライズ広告）は行いません
- 広告配信のために新たにメールアドレス以外の個人情報を収集することはありません
- アフィリエイトリンクを掲載する場合は、その旨をリンク付近に明記します

決済情報を扱うサブスクリプション等の機能は現時点で予定していません。

## 5. 情報の削除・開示請求

登録した銘柄はご自身で画面から削除できます。メールアドレスを含むすべての登録情報の削除、
または保有情報の開示をご希望の場合は、下記の連絡先までご連絡ください。折り返しご案内します。

## 6. 対象地域

本サービスは日本国内および米国在住の方を主な対象として提供しています。
**欧州経済領域(EEA)・英国・スイス在住の方への提供は行っておらず、これらの地域の方は
本サービスへのお申込みをご遠慮ください。** 本サービスはGDPR（EU一般データ保護規則）の
適用を前提とした体制を整えていません。
