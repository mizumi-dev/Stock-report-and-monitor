# シグナル点灯の実地検証（2026-08-02、マージ前の追加テスト）

## 背景

ユーザーから「レポートは届いているが、シグナルが点灯しているのを見たことがない」との
指摘。監視リストがNVDA・AAPLの2銘柄のみ、かつ登録から2日しか経っていないため、
「本当にロジックが壊れている」のか「たまたま点灯対象が少ないだけ」なのか区別できな
かった。`jstqb-test-process`スキルに沿い、実データで機能検証を実施。

## 実施内容

一時的な診断用コード（`_diagnostic_scan`イベントフラグ）を`handler.py`に追加し、
NASDAQ100の実データ103銘柄に対して全シグナルを計算・集計（メール送信はしない）。
検証後は`test-skip-review`スキルの「安全に実行する」パターンに従い、コードを
完全に元に戻して再デプロイ・ハッシュ一致を確認した（`handler.py`の差分なし、コミット
にも残していない）。

## 結果

| シグナル | 点灯数（対象101銘柄中） | 例 |
|---|---|---|
| buy_trend（ゴールデンクロス/並び順） | 19件 | AMGN, PCAR, PAYX, ADSK, ROST |
| sell_trend（デッドクロス/並び順） | 12件 | ODFL, SNPS, MSTR, ISRG, WMT |
| buy_momentum（RSI売られすぎ） | 9件 | INTC, SNPS, ISRG, MRVL, CDNS |
| sell_momentum（RSI買われすぎ） | 7件 | AAPL, CTAS, ROST, EA, CSX |
| volume_high（出来高急増） | 0件 | （最大倍率1.41倍、閾値1.5倍に僅かに届かず） |

RSIの分布は14.8〜82.6と閾値(30/70)を跨ぐ銘柄が実在することを確認。

保存済みの`signal_history`（NVDA・AAPL、2026-08-01/02分）でも実際の点灯を確認済み:
- AAPL 2026-08-01: 出来高急増(volume_high=True、倍率2.47)
- AAPL 2026-08-02: RSI買われすぎ(sell_momentum=True、RSI 73.8)

## 結論

**シグナル計算ロジックは正しく機能している。** ユーザーが「見たことがない」と感じたのは:
- 監視銘柄がNVDA・AAPLの2銘柄のみで、登録から2日しか経っていないため観測機会が
  少なかった（実際にはAAPLで2回点灯している）
- 出来高急増は元々発生頻度が低い条件（今回の全数調査でも103銘柄中0件）

新規に見つかった不具合はなし。`report.py`の表示ロジック（🟢/⚪、●/○のドット）も
シグナル値を正しく反映していることをコードレビューで確認済み。
